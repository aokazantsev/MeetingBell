# MeetingBell — инструкции для Claude

Поведение, настройки и файлы — в `README.md`, прочитать перед правкой. Здесь только правила работы.

## Устройство

- `EwsClient` — EWS по HTTPS, Basic, без перенаправлений: `FindItem` + `CalendarView` на сутки, затем один `GetItem`
  с текстом приглашений всех встреч (описание до 4000 символов; ссылка из текста — только встречам без ссылки на конференцию в месте). Из места и текста ссылкой встречи становится адрес известного сервиса конференций (`MeetingLinks.ConferenceHosts`); если его нет, `TrayApplication.UseLocationLinks` берёт первую http(s)-ссылку из места, и тогда на кнопке виден её хост (punycode). Отменённые (`IsCancelled`) и отклонённые
  (`MyResponseType=Decline`) встречи отбрасываются.
- `CredentialStore` — запись `MeetingBell:exchange` (Generic, `CRED_PERSIST_LOCAL_MACHINE`) в диспетчере учётных
  данных; удаляет её деинсталлятор (`UninstallProfile`).
- `ReminderPlanner` — чистая логика «когда напомнить»; ключ показанного напоминания — `UID|начало`, показанные
  хранятся в `today.txt`, отложенные — только в памяти.
- Почта: `EwsClient.InboxUnread` (GetFolder `inbox`, `folder:UnreadCount` — без подпапок), свой опрос в `TrayApplication` (`mailMinutes`, общий признак паузы после 401), строка внизу `MeetingListForm`; «Открыть» — `AppSettings.WebMailUrl` (свой адрес или `https://<хост EWS>/owa/#path=/mail`).
- `NewMeetingFinder` — встречи, которых не было в прежнем списке дня (по UID), начинающиеся не раньше чем за 30 минут до «сейчас», без встреч на весь день; при первой загрузке дня (`cache.Fetched` пуст) не зовётся. Уведомление — та же `ReminderForm` с заголовком, без «Через 1 мин».
- `MeetingPreferences` — своё время встречи по UID (вся серия), забывается через 100 дней без встречи в календаре.
- `TrayApplication` — таймер 15 с: проверка VPN (`VpnDetector`, адаптеры `NetworkInterface`), опрос раз в `CalendarMinutes` (по умолчанию 5 мин) в
  пуле потоков, напоминания. После 401/403 опрос стоит до сохранения настроек или «Обновить сейчас»; без паузы сохранение возобновляет опрос сразу, только если сменились креды или адрес.
- `MeetingListForm` — своё окно без активации (`WS_EX_NOACTIVATE`) над треем, рисуется вручную; прячется через
  400 мс после ухода мыши со значка и окна.

## Сборка

- Штатный `csc.exe` .NET Framework 4.8, **C# 5**: нет `$"..."`, `?.`, `nameof`, `=>`-членов,
  инициализаторов авто-свойств, `out var`.
- `build.cmd nostart` — программа, `build-installer.cmd` — установщик в `dist\` (в конце удаляет exe из корня),
  `tests\run.cmd` — тесты логики (пути данных подменяются отражением на временную папку).
- Работает без прав администратора: автозапуск — ключ Run, запуск из установщика — через `explorer.exe`.

## Проверка

- Живой EWS: `tests\run.cmd` собирает `tests\obj\MeetingBellTests.exe`; `MeetingBellTests.exe live [дата]` берёт
  адрес и логин из `EXCHANGE_EWS_URL`, `EXCHANGE_USERNAME`, `EXCHANGE_PASSWORD` и печатает только время и признаки
  встреч, без тем. Неверный пароль не проверять вживую: повторы блокируют учётную запись.
- Скриншоты README (`docs\*.png`) — обвязкой на синтетических встречах, без настоящих тем, адресов и логинов.

## Правила кода

- Комментариев нет, один класс — один файл, `if/else` вместо `switch` на две ветки.
- Таймеры не чаще раза в 5 с, кроме проверки ухода мыши (100 мс, только пока список открыт).
- Журнал не содержит тем, мест, участников, ссылок встреч, логина и пароля: только время, числа и ошибки.
  Новая строка журнала сверяется с «Что уходит в отчёте» в `SetupProfile`.
- Ссылка встречи открывается, только если это `http`/`https` без логина в адресе (`MeetingLinks.IsWebLink`):
  приглашение может прислать кто угодно.
- Ничего корпоративного в коде и README: адрес EWS по умолчанию — `mail.example.com`, адаптер — `Fortinet`.
- Системные программы — по полному пути из `SystemTools`.

## Грабли

- Heredoc в Bash ест обратные слэши — `.cmd` писать инструментом записи, затем перевести в CRLF.
- `.cmd` — CRLF и только ASCII.
